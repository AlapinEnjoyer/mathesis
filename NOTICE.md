## LearnHarness

Mathesis adapts ideas, tool shapes and prompt text from
[LearnHarness](https://github.com/amosblomqvist/learnharness) by Amos Blomqvist,
which is licensed under the GNU Affero General Public License v3.0.
Reference commit: `dc4c398d5167865b84b0ccb3ec809eb88bf8f65f` (2026-10-29).

Each adapted file starts with a comment of this form:

```
Adapted from LearnHarness (AGPL-3.0), <original path>, <date>; modified
```

Main changes: the learner is "the learner" (they/them), tools have Mathesis names,
LearnHarness-only UI references are removed, and spaced review (FSRS) is added.
